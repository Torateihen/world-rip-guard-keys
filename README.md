# world-rip-guard-keys

トマハト怒りのワールドリッピング対策ツール（松川怒りのシリーズ）の「鍵の外出し」機能（1.1）で、ワールドが起動時に読みに行く鍵ファイルの置き場です。

- 公開の場所です。ここにある鍵は誰でも読めます（ワールドの訪問者が読むための物なので、秘密ではありません）。
- 鍵を消すと、そのワールドは「閉場中」の表示になります（1.1 以降）。
- ファイルは `keys/<ワールドの識別子>.json` に置きます。今はまだ空です。

配信は GitHub Pages（`https://torateihen.github.io/world-rip-guard-keys/keys/<名前>.json`）。VRChat の String Loading の信頼済みドメイン（*.github.io）なので、訪問者側の設定変更は要りません。
